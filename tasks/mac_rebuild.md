# Macで、集計スクリプトを作り直す（Windowsのファイルが使えないため）

Windowsのパソコンが使えないので、Macで、集計スクリプトを作り直す。仕様は、CLAUDE.md の 1〜9章にある（特に9章）。

## やること（この順で）
1. CLAUDE.md を読んで、作り直すものを、短く、まとめる。分からない点があれば、ユーザーに聞く（推測で進めない）。
2. 環境の準備：Node.js の確認、npm の初期化と依存パッケージ（iconv-lite、csv-parse、exceljs）の追加。入れる前に、内容を見せて、許可をもらう。
3. master/流入元マスター.csv を、master/流入元_並び順.txt から作る（126行、重複行も、そのまま）。
4. 入力データを、ユーザーと一緒に用意する：フォーム回答CSV4つ（176252 / 178808 / 202523 / 205225）と、Product_selling CSV（9月分）。ダウンロードは、ユーザーの許可を取ってから、Chromeで行う（CLAUDE.md 9-1の経路）。ログイン画面が出たら、止まって、ユーザーに知らせる。
5. scripts/aggregate.js を作る（CLAUDE.md 9-2のとおり）。場所の書き方は、どのパソコンでも動くように（リポジトリからの相対の場所、ダウンロードはホームの Downloads）。
6. 9月分（9/1〜9/29）で、試しに実行して、検証用の数字（9-3）と照合する。申込件数（19歳以上1,143／18歳136／17歳以下207／年齢不明0）が、一致するまで、直す。一致しなければ、止まって、差を見せる。
7. 貼り付けファイルの作成（scripts/generate_paste_files.js）と、日報の作成を、作る（9-5、9-6）。スプレッドシートの行の対応表（master/sheet_row_map.json）は、ユーザーが、スプレッドシートを開いて、A列の流入元名を見せてくれたら作る（Googleには、ログインしない自動実行では、読めないため）。
8. ここまでが動いたら、毎日11時の自動実行（Playwrightで、AIを使わない）の設計を、tasks/daily_design_reply.md と tasks/mac_migration.md の方針に従って、進める。設定の変更は、ユーザーの許可なしに、行わない。

## 守ること
- input/、output/、scripts/daily/profile は、GitHubに上げない。
- エルメのデータは、読み取りだけ。設定変更、配信、メッセージ送信は、しない。
- 数字は、推測で埋めない。
