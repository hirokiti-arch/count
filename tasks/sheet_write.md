# スプレッドシートへの入力依頼（書き込み前に計画を提示）

対象：https://docs.google.com/spreadsheets/d/1UmdpphaOv7dYRnMHSUYB2kLclqZb8DJBMBBYGLRGeTM/edit?gid=2062213716#gid=2062213716

## ユーザーが決めたこと
1. 「不明」の件数（Excelの `ー` の行）は、スプレッドシートの `ー`（横棒）の行に入れる。`オーガニック` には入れない。
   - 理由：友だち追加のうち流入元が記録されていない人は、ブロックされて流入元が見えない人だから。
2. 「リスト」シートの申込み率の列（AH列）は、触らない。数式セルなので上書きしない。
3. 申込数は「申し込み数・配信スケジュール」シート、リスト数は「リスト」シートに入れる。
4. 「年齢不明_詳細」（個人情報）は、スプレッドシートに入れない。

## 進め方（まだ書き込まない）
1. 先の確認で分かったシート構成をもとに、9月分（9/1〜9/29）を、どのシートの、どのセル範囲に、何の数字を入れるかを、表にして提示する。
   - 流入元ごとに、セル番地・現在の値・入れる値、を並べる。
   - 数式が入っているセルは、入れる対象から外す。
   - Excelの `ー` の行の数字が、スプレッドシートの `ー` の行に入ることを、明記する。
   - 申込数は年齢区分（19歳以上／18歳／17歳以下）を、シートの構成に合わせて、どう入れるかも示す。
2. ユーザーが、提示内容を確認して、許可するまで、書き込まない。
3. 許可されたら、まず、1〜2セルだけ入れて、正しく入ったかを確認してから、残りを入れる。
4. 保護されたセルで権限エラーが出たら、止めて報告する。
5. 書き込み後、入れた範囲を、読み直して、Excelの数字と一致するかを確認して、報告する。

## 守ること
- ログイン画面が出たら、止まってユーザーに知らせる（パスワードは入力しない）。
- 既存の数字を上書きする場合は、上書き前に、元の値を一覧にして、ユーザーに見せる。
