# Macへの移行と、毎日11時の自動実行（Mac）

目的：集計と毎日の自動実行を、Windowsから、このMacに移す。Macは、画面を開いたまま、置いておく。

## 前提
- Windowsのパソコンの作業内容（scripts、master、tasks、CLAUDE.md）は、GitHubのこのブランチに、pushされている想定。されていなければ、ユーザーに伝えて、止まる。
- input/、output/、scripts/daily/profile（ブラウザのログイン情報）は、GitHubに上げない。
- 自動実行では、Claude Codeを使わない。権限チェックの省略は、行わない（tasks/daily_design_reply.md の方針のとおり）。

## やること（この順で）
1. 状態の確認：リポジトリの中身を見て、次を、短く報告する。
   - scripts/aggregate.js、master/流入元マスター.csv、master/流入元_並び順.txt、CLAUDE.md、tasks/ があるか。
   - scripts/daily/（Playwrightの自動実行プログラム）が、できているか、設計だけか。
2. 環境の準備：Node.js、依存パッケージ（npm install）、Playwrightのブラウザ（npx playwright install chromium）を、入れる。入れる前に、内容をユーザーに見せて、許可をもらう。
3. 場所の書き方を直す：scripts の中の、Windowsの場所（C:/Users/...、バックスラッシュ）を、すべて探して、どのパソコンでも動くように直す（リポジトリからの相対の場所、ホームの Downloads など）。
4. エルメ専用プロファイル：scripts/daily/profile を、Macで、新しく作る。setup_login.js を、画面ありで起動して、ユーザー自身が、エルメにログインする（パスワードは入力しない。Googleには、ログインしない）。
5. 試運転：9月分で、ダウンロード→集計→貼り付けファイル→日報を、1回、実行する。9月の数字（19歳以上1,143／18歳136／17歳以下207、9/29まで）と、一致するか照合して、結果を見せる。一致するまで、定期実行には、進まない。
6. 定期実行の設定（launchd）：毎日、午前11時に、node scripts/daily/run_daily.js を実行する設定を作る。登録する前に、内容（plistの中身、ログの出力先）を、ユーザーに見せて、許可をもらう。
7. スリープの対策：次を、ユーザーに案内する（設定の変更は、ユーザーが行う）。
   - システム設定で、電源接続時に、自動でスリープしない、にする。
   - 毎日10時55分に、起動（スリープ解除）する設定（pmset repeat など）を、提案する。実行前に、コマンドを見せる。
   - ログインしたままにする。
8. Windows側の、定期実行（タスクスケジューラ）が、登録されているか、ユーザーに確認してもらい、あれば、無効にしてもらう（二重実行を防ぐ）。
9. 終わったら、CLAUDE.md の、場所や手順の記述を、Macに合わせて更新する。

## 止まる条件
- ログイン画面が出たら、止まってユーザーに知らせる。
- 数字が、一致しなかったら、止まって、差を見せる。
- 設定の変更（システム設定、launchd、pmset）は、ユーザーの許可なしに、行わない。
