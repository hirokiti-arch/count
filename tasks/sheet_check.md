# スプレッドシート連携の確認依頼（読み取りのみ）

次のGoogleスプレッドシートを、Chromeで開いて、まず読むだけにしてください。書き込みはまだしないでください。
https://docs.google.com/spreadsheets/d/1UmdpphaOv7dYRnMHSUYB2kLclqZb8DJBMBBYGLRGeTM/edit?gid=2062213716#gid=2062213716

## 目的
今後、月次の集計結果を、このスプレッドシートに入力します。
- 申込数は、「申し込み数・配信スケジュール」のシートに入れます。
- リスト数は、「リスト」のシートに入れます。

## 確認して報告してください
1. 2つのシートの構成（見出しの行と列、流入元の並び順、日付の列の並び、9月分に当たる場所、すでに入っている数字の例）。
2. 私たちのExcel（流入別申込数、流入元別_リード数_申込率）の数字を、どこにどう入れると合うか、対応案。
3. 流入元の名前や並びが、スプレッドシートとExcelで違う点。
4. 数式のセルや、保護されていそうなセルがあれば、その場所。

## 守ること
- 個人情報（LINEユーザーID・LINE名）を含む「年齢不明_詳細」は、スプレッドシートに入れません。
- 書き込みは、報告を見て、ユーザーが許可してから、その場所と内容を確認したうえで行います。
- ログイン画面が出たら、止まってユーザーに知らせてください（パスワードは入力しません）。
