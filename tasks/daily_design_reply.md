# 設計案への返事（Playwright方式で進める）

この設計案で進めます。次の点を、設計に反映してください。

1. エルメ管理画面のURLは、ユーザーが別に伝える（このファイルの後に、ユーザーが入力する）。足りない分だけ、ユーザーに聞いてください。
2. 日別の友だち追加数の取得方法
   - 友だち一覧（約3.2万人）の全件CSVを毎日出すのは重いので、まず、画面に日別の友だち追加数（純増ではなく、追加数）を出す場所（統計・分析など）が無いかを探してください。
   - 次に、友だち一覧の「追加日」で1日だけ絞り込んで、件数を読み取る方法を検討してください。
   - どの方法でも、これまでMCP（filter_friends、day_add_friend、bot_id=23ZloW）で取っていた数字と、一致することを確認してから採用してください。照合用の数字（エルメの友だち追加数）：9/24=134、9/25=131、9/26=113、9/27=137、9/28=126、9/29=108、9/30=134。
3. 対象のスプレッドシートは、月ごとに変わる可能性がある（今は「2026_09売上管理表」）。月の変わり目に、sheet_row_map.json と、貼り付け先の列の位置を、作り直す手順を、設計に入れてください。月が変わったことを、日報に書いて、ユーザーに知らせてください。
4. 定期実行に登録する前に、試しに1回、実行してください。9月分の数字（申込1,478件＝19歳以上1,137／18歳135／17歳以下206／年齢不明0。9/29までの完結した数字に更新後は、日報の1,486件などを基準にしてください）と、リード数、ー の値が、すでに確認した数字と一致するかを照合して、結果を、見せてください。
5. 貼り付けファイルは、当日と前日の2日分です。手順書（CLAUDE.md）8章の「直近3日分」の文言は、2日分に揃えてください。
6. 自動実行では、Claude Codeを使わないでください。権限チェックの省略は、行わないでください。
